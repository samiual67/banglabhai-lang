Conditionals
jodi bhai, othoba bhai, nahoy bhai.


shuru bhai
  bhai eta holo a = 10;
  jodi bhai (a < 5) {
    dekha bhai "choto";
  } othoba bhai (a < 20) {
    dekha bhai "majhari";
  } nahoy bhai {
    dekha bhai "boro";
  }
shesh bhai


Loops
jotokkhon bhai, thamo bhai (break), porerta dekh bhai (continue).


shuru bhai
  bhai eta holo a = 0;
  jotokkhon bhai (a < 10) {
    a += 1;
    jodi bhai (a == 5) { porerta dekh bhai; }
    jodi bhai (a == 8) { thamo bhai; }
    dekha bhai a;
  }
shesh bhai
